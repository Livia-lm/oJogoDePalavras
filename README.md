# oJogoDePalavras

## Testes automatizados

O protótipo interativo pode ser validado com Node.js 18 ou superior:

```sh
npm test
```

Os testes executam o JavaScript embutido em `prototipos.html` e cobrem validação de palpites, feedback, repetição, acerto, desistência, troca de temas e fluxo de treino. Como o projeto ainda é um protótipo com proximidade simulada, eles não validam uma API, persistência ou similaridade semântica real.
